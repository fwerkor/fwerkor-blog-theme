# FWERKOR Blog Theme

A lightweight WordPress theme for FWERKOR Blog, visually aligned with Auctor while keeping a content-first technical-blog layout.

## Design

- restrained Material-inspired surfaces and spacing;
- responsive article feed with a useful sidebar;
- long-form technical article typography;
- native WordPress custom logo, menus, widgets, comments and featured images;
- no frontend framework, jQuery dependency, remote font, or build step;
- mobile-first navigation and search.

## Installation

Copy the repository into wp-content/themes/fwerkor-blog and activate FWERKOR Blog in WordPress.

## Theme features

- custom logo
- primary and footer menu locations
- dedicated FWERKOR Sidebar widget area
- featured images
- responsive embeds
- HTML5 markup
- archive, search, page, single, comments and 404 templates
